# Cloud

Source: https://docs.coralos.ai/reference/server/cloud

# API key
**default** `undefined`

- Command line: `--cloud.api-key="coral_...."`
- Config file: `cloud.api_key = "coral_...."`

Specifying a [Coral Cloud API key](https://coralcloud.ai/account) enables Cloud-powered features in Coral Server and Coral Console.
